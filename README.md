# RailConnect — Railway Information System

A responsive six-page front-end website created with HTML5, CSS3 and vanilla JavaScript for an academic project.

## Pages
1. `index.html` — Home dashboard and module overview
2. `trains.html` — Searchable and filterable train directory
3. `routes.html` — Route cards and sample route information
4. `tickets.html` — Journey enquiry form with client-side validation
5. `stations.html` — Station directory and example passenger facilities
6. `services.html` — Passenger support information and contact form

## Run
Open `index.html` in a modern browser. Internet access is required for Google Fonts and the remote Unsplash photographs. All page styling and JavaScript are local in `css/` and `js/`.

## Academic/demo notice
This is a front-end demonstration. Train information, distances, facilities and schedules are sample content and may not be current or accurate. The forms do not connect to a railway database, payment gateway or ticket reservation service. For real travel, verify details with official railway channels.

## Suggested professor-level extensions
- Connect a backend (Node.js/Express or Java Spring Boot) and MySQL database.
- Add authentication with role-based access for passengers and administrators.
- Integrate a verified train timetable API and real-time running status provider.
- Add server-side validation, secure sessions, audit logs and accessibility testing.
